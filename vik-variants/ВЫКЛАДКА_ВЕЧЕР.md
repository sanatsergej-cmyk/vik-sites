# Выкладка сегодня вечером: пошагово

Что получится: `vikmsk.ru` — страница выбора из трёх вариантов; `gold.vikmsk.ru`, `kp.vikmsk.ru`, `indigo.vikmsk.ru` — сами сайты; `app.vikmsk.ru` — CRM (по желанию сегодня). Всё закрыто от индексации.

## 1. DNS (в панели Beget, домен vikmsk.ru)

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | IP сервера |
| A | `*` | IP сервера (покрывает gold, kp, indigo, app) |

MX и TXT для почты Яндекс 360 — отдельно, сайту не мешают.

## 2. Сервер (один раз)

Нужен доступ по SSH (логин, IP; пароль вводите сами). На сервере: Caddy (сам выпускает SSL) и rsync; для CRM — Docker.

Папки: `/srv/vik-chooser`, `/srv/vik-v1`, `/srv/vik-v2`, `/srv/vik-v3`.

Caddyfile на сервере:
```
{$SITE_DOMAIN} {
	root * /srv/vik-chooser
	header X-Robots-Tag "noindex, nofollow, noarchive"
	file_server
}
```
плюс содержимое `vik-variants/deploy/Caddyfile.variants`, запуск с `SITE_DOMAIN=vikmsk.ru`.

## 3. Выкладка с Mac

```
rsync -az vik-variants/chooser/ user@IP:/srv/vik-chooser/
DEPLOY_HOST=user@IP ./vik-variants/deploy/deploy-variants.sh
```
Скрипт сам соберёт три сайта, проверит тексты и закрытость robots.txt.

## 4. Формы и консультант (чтобы заявки реально приходили)

Сейчас формы в тестовом режиме: всё работает, но заявка никуда не уходит. Чтобы заработали:
1. Поднять CRM: `vik-crm/` → `docker compose up -d` на сервере, заполнить `.env` по `.env.example` (секреты задаёте сами; для уведомлений в Telegram нужен токен бота и chat id).
2. В CRM: `PUBLIC_LEADS_ENABLED=1`, `PUBLIC_SITE_ORIGINS=https://gold.vikmsk.ru,https://kp.vikmsk.ru,https://indigo.vikmsk.ru`.
3. На сайтах: `PUBLIC_FORM_ENABLED=1` при сборке (`PUBLIC_FORM_ENABLED=1 DEPLOY_HOST=… ./deploy-variants.sh`).

Важно: до уведомления РКН, утверждения политики/согласия юристом и решения по Telegram (трансграничная передача) принимать заявки от посторонних нельзя. На закрытом стенде включаем только для проверки своими данными.

## 5. После выбора Виталием

Выбранный вариант кладём на `vikmsk.ru` (вместо страницы выбора), остальные поддомены выключаем. Индексацию (`ENABLE_PUBLIC_INDEXING=1`) включаем только после юрлица/СРО/РКН.
