## 4. Анимация и эффекты (главная идея — «сборка сетей при прокрутке»)

- Сквозной трубопровод: SVG-линия (line art) рисуется по мере прокрутки от первого экрана до формы, на ней «узлы» этапов загораются; при прокрутке вверх откатывается. Вариант V3 дополнительно делает изометрический разрез здания с сетями под землёй (идея концепции №1), собирающийся по слоям.
- Параллакс слоёв на первом экране, мягкое появление блоков, счётчики/ленты этапов. Всё на чистом JS (requestAnimationFrame + scroll progress, IntersectionObserver) или CSS scroll-driven animations с JS-фолбэком. Без тяжёлых библиотек; если очень нужно — локально через npm, без CDN.
- `prefers-reduced-motion: reduce` — анимации выключены, контент виден сразу. Ничего не должно прятать текст от поисковика/без JS.
- Видео генерировать нельзя: баланс Polza пуст (0,95 ₽), платные API не вызывать. Локальный рендер короткой петли через Hyperframes/Remotion допустим только если укладывается без сети и не тормозит страницу (не обязателен).
- Референсы стилей motion: https://vincentwei1021.github.io/mg-styles-15/ (Line Art №4, Isometric 2.5D №2, Shape Morph №6, Aurora/Glass №10).
