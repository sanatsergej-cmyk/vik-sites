# vik-site — сайт ВиК (Astro 7)

Закрытый стенд (noindex) инжиниринговой компании ВиК. 22 страницы: главная, 5 направлений, 9 услуг, о компании, проекты, документы, контакты, политика, согласие, 404.

## Сборка и просмотр

```bash
node scripts/build-kb.mjs        # база знаний консультанта (public/kb.json)
node scripts/check-content.mjs   # проверка текстов: должно быть «ОШИБКИ (0)»
npx astro build                  # → dist/
python3 -m http.server 4401 --directory dist   # http://localhost:4401/
```

Тексты: только `src/content/*` (единый источник, его же импортируют варианты V2/V3). Флаги: `.env` (описание в `.env.example`): `ENABLE_PUBLIC_INDEXING`, `PUBLIC_FORM_ENABLED`, `PUBLIC_LEAD_ENDPOINT`, `PUBLIC_CLIENTS_BLOCK`, `PUBLIC_PHOTOS`, `PUBLIC_VARIANTS`. Выкладка: `deploy/README.md`.

## V1 «Золото»: что сделано, решения, недочёты (01.11.2026)

### Что сделано

- **Главная** (`src/pages/index.astro`). Первый экран: эмблема (вырезанный треугольник из выбора Виталия №6 с мягкой альфа-маской), «ВиК», слоган, принципы, h1, CTA, срок первичной оценки. - **Сквозной трубопровод** (`src/components/PipelineScene.astro`, заменил старую горизонтальную схему). SVG-линия идёт из центра под первым экраном в левый коридор, через П-образные компенсаторы, до формы `#intake`, рисуется по прокрутке со светящейся «головой» и откатывается при прокрутке вверх. Пять узлов `route` стоят на секциях: 01 «стадии», 02 «услуги», 03 «что снижает риск», 04 «СМР по системам», 05 форма. Когда линия доходит до узла, загораются узел и метка «Этап 0X» в секции.
- **Новые блоки главной:** «СМР по системам» (5 карточек; тепло, вентиляция, электро — реальные фото из `photos.mjs`; вода и газ — кадры из концепций 09.10 с подписью «Иллюстрация»; на телефоне горизонтальная лента), «Технический заказчик: что входит» (5 раскрывающихся блоков из `services` → `technical-customer`), «Миссия» с пометкой «проект миссии», маршрут проекта в духе концепций №1 и №6 (разрез здания + вертикальная лента этапов). `ClientsBlock`, `Gallery` переверстаны в общий стиль.
- **Направления** (`napravleniya/[slug].astro`): свой оттенок золота у каждой системы (`src/data/visual.ts`: белое, красное, жёлтое, зелёное, янтарное), иконка в кольце, анимированная line-art схема системы (`SystemArt.astro`: колодец и ввод воды; теплосеть с компенсатором, камерой и ИТП; КТП и кабельная линия; воздуховод с вращающимся вентилятором; газопровод с краном и ШРП), реальные фото глубже по странице, переключатель «Другие системы» и «На главную».
- **Остальные страницы** приведены к тому же уровню: услуги (ситуации в шапке, бенто-блоки состава, лента шагов, результат/факторы, границы ответственности), о компании, проекты (пустое состояние + маршрут), документы, контакты, политика, согласие, 404.
- Общее: плавающая шапка-пилюля (прячется при прокрутке вниз), полноэкранное меню на телефоне, кнопки-пилюли с вложенной иконкой, двойные рамки, появление блоков при прокрутке, зерно поверх страницы, новый подвал.
- Ассеты: `public/brand/marble.(webp|jpg)` — чёрный мрамор с золотыми прожилками, сгенерирован локально (numpy); `public/brand/emblem-cut.(webp|png)`; `public/art/*` — кадры концепций; webp-версии фото (`public/photos/*.webp`, `*-480.webp`). Все картинки через `<picture>` (webp + jpg/png), `loading="lazy"`, размеры указаны.
- `.env`: `PUBLIC_VARIANTS=0` (код переключателя оставлен, скрипт варианта в `<head>` теперь тоже выполняется только при флаге). Остальные флаги не трогал.

### Решения

- Шрифты системные (Iowan Old Style / Palatino / Georgia для заголовков, system-ui для текста), никаких CDN.
- Анимации на чистом JS (rAF + IntersectionObserver), без библиотек. При `prefers-reduced-motion` трубопровод показан целиком, узлы горят, появления выключены. Без JS весь текст виден: скрытие при появлении включается только классом `motion`, который ставит скрипт.
- Узлы трубопровода считаются по `offsetTop` секций (не зависят от transform и sticky), трасса пересчитывается через ResizeObserver.
- В тексты добавлены только служебные подписи блоков в `pages.mjs` (`home.smr`, `home.techCustomer`, `home.missionNote`), они пересказывают существующие формулировки. По газу в подписи прямо сказано, что состав строительных работ определяется после изучения ТУ и проекта.
- Скриншоты: `screens/` (главная и теплоснабжение на 1440 и 390, полные страницы главной и направлений).

### Недочёты и что осталось

- Для водоснабжения и газоснабжения нет реальных фото: стоят ИИ-кадры из концепций с подписью «Иллюстрация». Нужны фото от Виталия.
- Фото и блок заказчиков показываются только на закрытом стенде (`PUBLIC_PHOTOS=1`, `PUBLIC_CLIENTS_BLOCK=1`). Если выключить фото, карточки СМР по теплу, вентиляции и электро переходят на line-art схемы.
- Эмблема на первом экране — растровая ИИ-картинка (825×575); векторная версия есть (см. ниже), но в hero уступает растру по объёму и блеску.
- На узких десктопах (960–1100 px) коридор для трубопровода узкий, компенсаторы не рисуются; на телефоне линия идёт по краю экрана без номеров узлов.
- Плейсхолдеры адреса в `documents.requisites`, политике и согласии кто-то заменил на «г. Москва» (в ТЗ требуется формат `XXXX`). Агент V1 этого не менял, нужно решение владельца.
- Неиспользуемые старые ассеты `public/brand/emblem-staging.jpg` и `marble.svg` оставлены, их можно удалить.
